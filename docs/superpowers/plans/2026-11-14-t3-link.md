## Task B: the server module over the t3 CLI

`src/server/t3.ts`. The only code that runs `t3`. Nothing calls it yet; #721 and #537 will.

```ts
export interface T3Thread { threadId: string; projectId: string; title: string; link: string; status: string;
  runtimeMode: string; settled: boolean; archived: boolean; pendingRequestCount: number; updatedAt: string;
  createdBy: string; creationSource: string }
export interface T3Message { role: string; text: string }
export class T3Unavailable extends Error {}
/** Runs one command. Injected in tests. Rejects on a non-zero exit, a timeout or a missing file. */
export type T3Run = (file: string, args: string[], opts: { timeoutMs: number; input?: string; verbatim: boolean }) => Promise<string>;
export interface T3Options { run?: T3Run; cliPath?: string; platform?: NodeJS.Platform }
export function t3CliPath(env?: Record<string, string | undefined>): string;
export function t3CommandLine(cli: string, args: string[], platform: NodeJS.Platform): { file: string; args: string[]; verbatim: boolean };
export function t3List(project?: string, o?: T3Options): Promise<T3Thread[]>;
export function t3Show(threadId: string, o?: T3Options): Promise<{ thread: T3Thread; messages: T3Message[] }>;
export function t3Start(project: string, message: string, opts: { provider: string; model: string; title?: string; worktree?: string; branch?: string }, o?: T3Options): Promise<{ threadId: string }>;
export function t3Send(threadId: string, message: string, o?: T3Options): Promise<void>;
```

- `t3CliPath`: `T3CODE_CLI_PATH`, else `~/.t3/bin/t3.cmd` on Windows and `~/.t3/bin/t3` elsewhere.
- `t3.cmd` is a batch file, and Node refuses to run one without a shell. So on `win32`, `t3CommandLine` returns
  `file` = `ComSpec` or `cmd.exe`, `args` = `['/d', '/s', '/c', '"' + [cli, ...args].map((a) => '"' + a + '"').join(' ') + '"']`
  and `verbatim: true` (the real runner passes `windowsVerbatimArguments`). Elsewhere it returns the CLI and the
  args unchanged, `verbatim: false`.
- Because a shell is involved, every argument is checked before anything runs. A project, thread id, provider,
  model, worktree or branch containing any of `" % ^ & | < > !` or a control character throws `TypeError` and runs
  nothing. A title has those characters replaced by a space and is cut to 120 characters. The message never goes on
  the command line: the argument is `-` and the text goes to stdin.
- Calls: `thread list [--project <project>] --json`; `thread show <id> --json`;
  `thread start <project> - --provider <p> --model <m> [--title <t>] [--worktree <w>] [--branch <b>] --json`;
  `thread send <id> - --json`. No `--wait`: InProgress never blocks on a model.
- Limits: 30 seconds for `list` and `show`, 60 for `start` and `send` (on a loaded machine a list took 17 seconds).
  `t3List` always names its project: without one the CLI uses the folder the server runs in. The real runner is `execFile` with
  `windowsHide: true`, written like `run` in `src/server/sync.ts:92`.
- Output is parsed with zod. Unknown keys are ignored. `settled` and `archived` default to `false`,
  `pendingRequestCount` to `0`, and `updatedAt`, `createdBy` and `creationSource` to `''`. `start` needs `threadId`.
- Any failure to run or to parse (missing file, non-zero exit, timeout, bad JSON, wrong shape) throws
  `T3Unavailable` with the cause in its message. `TypeError` is only for a bad argument.

**Tests** (`test/server/t3.test.ts`, all with an injected `run`): `t3Show` parses a fixture with `thread` and two
messages; `t3List` parses a two-thread array and fills the defaults when `settled` is absent; `t3Start` returns the
`threadId` `mcp:abc`, passes `-` and sends the message as input, and puts `--provider` and `--model` in the args;
a runner that rejects, a timeout, `not json` and `{}` each throw `T3Unavailable`; a project of `C:\a"&calc` throws
`TypeError` and the runner is never called; a title of `Fix "it" & 100%` reaches the args as `Fix  it    100 `;
`t3CommandLine` on `win32` returns the `cmd.exe` shape above, and on `linux` returns the args unchanged.
